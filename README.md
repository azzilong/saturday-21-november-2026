A broadsheet front page that sums up the world's news of Saturday 21 November 2026 in one image: 35 dated stories across 7 regions — COP31 running into overtime in Antalya, five Houthi missiles shot down over Saudi Arabia, a magnitude 6.7 earthquake in Peru, and 32 more — with a world map, a stat strip, and a DATE CHECK box that names what was deliberately left out because it belonged to another day. The page is drawn in code (tools/render.py) and the entry program copies the finished PNG to /output/entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
